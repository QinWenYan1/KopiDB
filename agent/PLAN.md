当前固定读写格式（第二版实现草案；文件不写格式标识或版本号）：

| 顺序／偏移 | 内容 |
| --- | --- |
| 0、8、16、24 | 下一个 ID、flushed 数量、ready 数量、aborted 数量；均为 8 字节无符号小端整数 |
| 32 起 | flushed 的各 ID，按 set 升序，每项 8 字节 |
| 随后 | ready 的各 ID 与状态编码，按 map 升序，每对 16 字节；提交编码 0、回滚编码 1 |
| 最后 | aborted 的各 ID，每项 8 字节；不要求 unordered_set 输出顺序 |

写入：持管理器锁，先构造完整内存缓冲区；拒绝空 flushed 集合或已回绕为 0 的下一个 ID，拒绝未知结束状态。编码成功后关闭旧句柄，以截断模式重新打开状态文件，检查 write 与 sync 结果；不消耗事务 ID。读取按同一布局解码到临时容器，校验数量与实际长度、非空刷盘集合、正的下一个 ID、ID 重复或集合顺序及合法状态编码；全部验证成功后才更新成员。空文件和不符合当前布局的内容明确报错，不回退为新库。

验收：保存后能恢复一致的必要状态，包括 ID 分配信息和回滚名单；重复保存与读取结果正确；较短的新内容不残留旧尾部；读写失败明确上报；截断或不合法文件不能静默当作新数据库。当前仅确定格式和提供写入草案，读取函数尚未实现。
